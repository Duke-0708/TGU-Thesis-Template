# 天津工业大学 (TGU) 学位论文 LaTeX 模板

这是一个为天津工业大学（Tiangong University, TGU）硕博士学位论文设计的 LaTeX 模板。该模板遵循学校的论文格式要求，提供了一个结构清晰、易于配置的排版基础。

## 适用范围

模板内建了条件编译开关，支持一键切换以下论文类型：
*   **博士 (Doctor) / 硕士 (Master)**
*   **学术型 (Academic) / 专业型 (Professional)**
*   （对于专业型硕士，额外支持全日制/非全日制选项配置）

## 文件结构

*   `main.tex`: 主文档文件。包含了所有的宏包引用、样式设置、文档结构（如封面、摘要、目录、正文章节、参考文献及致谢等）。
*   `refs.bib`: 参考文献数据库文件。在此处添加你的 BibTeX 格式的参考文献条目。
*   `gbt7714-numerical.bst`: 参考文献国标样式文件，确保引用格式符合 GB/T 7714 标准。
*   `figs/`: 图片文件夹。用于存放论文中需要引用的图片，模板自带的 `校徽.png` 等文件也存放在此。
*   `论文格式要求.pdf`: 学校官方发布的学位论文格式要求规范文档（参考用）。

## 使用说明

### 1. 配置学位与类型
打开 `main.tex` 文件，在最开始的“硕博/学术专业 切换开关”部分，根据你的实际情况注释/取消注释相应的行：

```latex
% --- 修改此处进行切换 ---
% \doctortrue      % 取消注释表示“博士”，注释掉表示“硕士”
% \doctorfalse   % 显式指定为硕士

\academictrue    % 取消注释表示“学术型”，注释掉表示“专业型”
% \academicfalse % 显式指定为专业型
```

### 2. 填写封面信息
在 `main.tex` 的 `\begin{titlepage}` 环境中，找到对应位置填写：
*   分类号、学校代码
*   中英文论文题目
*   作者、导师、学院及学科（专业）信息
*   答辩委员会信息及日期

### 3. 编写正文内容
模板在 `main.tex` 中提供了章节示例。你可以在 `\mainmatter` 之后直接编写正文，或者使用 `\include{...}` 将不同章节拆分为独立文件进行管理。

### 4. 参考文献
本模板使用了 `gbt7714` 宏包和 `natbib` 来处理参考文献。在正文中通过 `\upcite{引用标签}` 添加上标形式的引用，或者直接使用 `\cite{}`。

### 5. 编译方式
由于模板使用了 `ctexbook` 文档类和中文字体配置，建议使用 **XeLaTeX** 引擎进行编译。一般推荐的编译顺序如下，以确保交叉引用和参考文献正确生成：
1. `xelatex main.tex`
2. `bibtex main`
3. `xelatex main.tex`
4. `xelatex main.tex`

如果你使用的是类似 TeXstudio、VS Code (LaTeX Workshop) 或 Overleaf 等编辑器，建议将默认的编译链设置为 `XeLaTeX -> BibTeX -> XeLaTeX -> XeLaTeX` (或使用 `latexmk -xelatex`)。

## 格式特性
*   自动生成适应不同学位类型的封面布局。
*   根据章节自动生成正确的页眉（奇数页章节名，偶数页学校及学位类型）。
*   内置了规范的各级标题字体和间距设置。
*   图表、公式的编号自动按章节重新编号（如 图1-1，公式2-1）。
*   默认设置英文字体为 Times New Roman，正文中文为宋体，标题为黑体。
